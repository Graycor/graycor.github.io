      How to get a Google Books key, and lock it down
      1. In Google Cloud console, create a project (or pick one) and enable the Books API. It is free and needs no billing account.
      2. Under APIs and services, Credentials, create an API key.
      3. Edit the key. Set Application restrictions to Websites and add https://graycor.github.io/*.
      4. Set API restrictions to Restrict key, and tick only Books API.
      5. Paste it above. BookScan checks it works here and warns you if it would work from anywhere.

      A key in a web page is visible to anyone using that browser, which is why Google lets you restrict it. Never paste a service account file, a client secret or a password here: BookScan refuses them.
